This guide explains how to host Revit Geometry Lab on GitHub Pages, what happens behind the calculator, and how to use its results in Revit families. The complete site is a collection of static files, so it can run without a server application or build tool.

1. Set up GitHub Pages

Use a repository named revit-geometry-lab, or choose a different name. The supplied relative links work under a repository URL without changing asset paths.

  1. Extract the ZIP. Inside the revit-geometry-lab folder, locate index.html, styles.css, app.js, geometry.js, and this guide.
  2. Create a GitHub repository. A public repository can use GitHub Pages on GitHub Free.
  3. Upload the folder's contents to the repository root, then commit to main. Do not upload only the ZIP or place the site inside another nested folder.
  4. Include the empty .nojekyll file. If it is missing after upload, use Add file → Create new file to create .nojekyll at the repository root, then commit it.
  5. Open Settings → Pages. Under Build and deployment, select Deploy from a branch, then choose main and /(root). Save the settings.
  6. Wait for the Pages deployment to succeed. Use the address shown in Settings → Pages; deployment errors appear in the Actions tab.

For Jeff's account and the suggested repository name, the expected URL is https://jeffthomasiii.github.io/revit-geometry-lab/. This is an example, not confirmation of an existing deployment.

GitHub Pages publishes a website to the internet. The access restrictions of the original private prototype are not included in this package.

Official setup references: Configure the publishing source and Create a Pages site.

Preview on your computer

Open index.html for a basic preview. For reliable local clipboard support, serve the extracted folder using Python, then open http://localhost:8000/.

python -m http.server 8000

Python is optional and used only for local preview. The hosted site does not require Python, Node.js, npm, or a server runtime.

2. Use the calculator

  1. Choose Right triangle or Circle & arc.
  2. Select your known-value pair. Two angle inputs alone cannot establish the size of a right triangle, so that pair is not offered.
  3. Choose mm, cm, m, in, or ft. Enter positive decimal dimensions; enter angular values in degrees.
  4. Review the geometry and calculated values. Green labels identify calculated triangle sides; lighter labels identify known triangle sides. The circle diagram identifies radius, chord, sagitta, central angle, and arc length.
  5. Optionally expand Use your parameter names. Enter the exact names used in your family, preserving capitalization. Use distinct names without formula operators or reserved function names.
  6. Create the parameters in Revit's Family Types dialog using the correct data types. Keep known values as editable inputs, then paste expressions into the calculated parameters' Formula fields.
  7. Click Copy beside a calculated result. The clipboard receives only the expression, not the target parameter or equals sign.
  8. Flex the family through its intended range. Check geometry and constraints as well as numerical results.

Changing the unit reinterprets the numbers rather than converting them. For example, changing 300 mm to ft produces an input of 300 ft, not its equivalent in feet. Switching tools or reloading clears the working inputs and custom parameter names.

3. Worked examples in Revit

Example A: a 300 × 400 right triangle

Choose a + b, millimeters, a = 300, and b = 400. The resulting hypotenuse is 500 mm, A is approximately 36.86990°, and B is approximately 53.13010°.

Rename a to Rise, b to Run, c to Slope Length, A to Slope Angle, and B to Complement Angle. Create Length parameters for the three sides and Angle parameters for the two angles.

ParameterInput or Formula field
RiseInput: 300 mm
RunInput: 400 mm
Slope Lengthsqrt(Rise^2 + Run^2)
Slope Angleatan(Rise / Run)
Complement Angle90° - Slope Angle

The Complement Angle expression depends on Slope Angle. Copying one formula does not create its referenced parameters automatically; create the parameters and supply all required inputs or formulas.

Example B: a chord and an arc height

Choose C + S, millimeters, C = 600, and S = 100. The resulting radius is 500 mm, included angle is approximately 73.73980°, and arc length is approximately 643.50111 mm.

ParameterFormula field
R, LengthC^2 / (8 * S) + S / 2

Here, T depends on R, and L depends on both R and T. Keep C and S as Length inputs and avoid applying a conflicting formula to either known input.

4. How the tool works

The interface collects your tool, known pair, units, and optional parameter names. The solver returns two things: numerical geometry values and symbolic Revit expressions for the unknown parameters.

The browser calculates numbers using JavaScript trigonometric functions, which use radians internally. The solver converts angular inputs from degrees to radians and angular results back to degrees. The displayed Revit expressions use Revit's angle conventions instead of JavaScript syntax.

Triangle relationships

The solver combines the Pythagorean theorem with sine, cosine, tangent, and their inverse functions. It uses a / c = sin(A), b / c = cos(A), a / b = tan(A), and A + B = 90°.

Circle relationships

For radius R and central angle T, the chord is 2 * R * sin(T / 2), the short sagitta is R * (1 - cos(T / 2)), and the arc length is R * (T / 180°) * pi(). The angular ratio in the arc-length formula is dimensionless, keeping the result a Length.

For chord C and sagitta S, the radius is C^2 / (8 * S) + S / 2. Other supported input pairs rearrange these relationships; the resulting parameter formulas may depend on intermediate parameters such as R or T.

Validation and display

The interface rejects empty, zero, negative, nonfinite, or geometrically impossible inputs. It also rejects conflicting parameter names before creating the expression list. Numerical results are rounded to five decimal places for display; the underlying calculation retains JavaScript's floating-point precision.

SVG diagrams update as inputs change. They illustrate relationships rather than providing drafting geometry; very narrow triangle legs have a minimum display size to keep labels visible.

Data and privacy

All calculations run locally in the visitor's browser. The application includes no database, login, analytics, external font library, or API request for input data.

Your working values and parameter names are held in memory only. They are not saved across a page reload or tool change; normal hosting services still process page requests, and external reference links open their respective websites.

Verification status

The included Node.js tests exercise all 15 supported input pairs, scaling, the semicircle boundary, and invalid-geometry rejection. These checks verify numerical relationships; they do not run Revit or certify that every generated expression will be accepted in every family or Revit version.

Test formulas in a disposable family with the intended parameter types before adopting them in production. Flex the family across its actual design range to confirm that its constraints behave correctly.

Commit changes to the configured publishing branch to update the website. Keep asset URLs relative and update both the mathematics and expression templates if you add a solver option.

node tests/geometry.test.cjs
node --check app.js
node --check geometry.js

There is no package installation or compilation step. An installable PWA, saved profiles, major-arc solver, and direct Revit integration are outside the current package.

6. Troubleshooting

IssueWhat to check
GitHub Pages returns 404Confirm index.html is at the selected publishing root, Pages points to main and /(root), and deployment succeeded. Use the exact URL in Pages settings.
Styles or scripts are missingUpload every source file. Preserve filename capitalization and relative paths; do not move app.js or geometry.js into another folder without updating index.html.
Old version still appearsConfirm the latest commit deployed successfully, then reload with cache bypass or try a private browser window.
Copy does not workUse the HTTPS Pages address or localhost. If clipboard access is blocked, select the visible expression manually, excluding its target name and equals sign.
Revit reports inconsistent unitsCheck Length, Angle, and Area data types. Use angle parameters for A, B, and T. Keep the explicit degree unit in angle constants and the arc-length expression.
Revit cannot recognize a parameterCheck capitalization, spaces, reserved names, and spelling. Create every referenced parameter; the calculator does not create parameters in Revit.
Revit reports a circular referenceKeep the two known parameters as inputs. Apply formulas only to the unknown parameters and avoid an existing reverse dependency elsewhere in the family.
No valid solution is shownReview the positive-value and angle limits. The hypotenuse must exceed a leg; the minor-arc sagitta cannot exceed half the chord.
